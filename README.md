## Запуск первой программы

Откройте терминал в папке проекта, где находятся `main.go` и `go.mod`.

```text

```

## Что осталось сделать

Карточка (cmd/card)
При изменении имени в коде и числа завершённых работ значения в выводе меняются.

Конвертер (cmd/time-converter)
Входные данные проверены вручную, результаты совпадают с ожидаемыми:
| Ввод | Полных часов | Оставшихся минут | Поведение |
|---:|---:|---:|---|
| 0 | 0 | 0 | Корректный результат |
| 59 | 0 | 59 | Корректный результат |
| 60 | 1 | 0 | Корректный результат |
| 125 | 2 | 5 | Корректный результат |
| 1500 | 25 | 0 | Корректный результат (часы не обнуляются после 24) |
| -1 | — | — | Сообщение об ошибке: отрицательное значение |
| abc | — | — | Сообщение об ошибке чтения числа |

Проверено: проект запускается локально.
